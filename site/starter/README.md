# Fantasy Audiobook Studio: starter kit

Skills for Claude Code that take a one-line idea to a finished, chaptered audiobook of a short fantasy novel:
brainstorm → story bible → outline → chapters → edits → fixes for the ear → local narration (Kokoro) →
automatic listen check → .m4b audiobook.

How it works, with a five-minute video and every skill explained: https://jca374.github.io/fantasy-audiobook-studio/

## Start

```bash
cd my-audiobooks        # this folder
claude
```

Then ask: **"Read SETUP.md and set this up for me."** When it's done: **"Start a new book with story-seed."**
