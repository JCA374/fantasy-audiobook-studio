# Pronunciation glossary

Every name or invented term, with how it is said. narration-prep turns the Phonemes
column into Kokoro markup (`ok` = Kokoro already says it right, `?` = to decide).
Check with: `.venv/bin/python .claude/skills/narration-prep/scripts/g2p.py <word> "<respelling>"`
All names were chosen by Claude (2026-10-21, author's "you make all the choices"); all are ordinary English words or names, so none needs markup.
